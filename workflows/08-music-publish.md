# Skill 8 — 發布內容生成（music-publish）

## 目標
根據歌曲資訊，一次產出所有社群發布所需的文案素材。

## 輸入
- 歌曲名稱
- `YT.txt`：格式化歌詞
- YT 影片連結（上線後補入）
- 鏡00 圖片（建議優先作為封面）

## 輸出
1. YT 影片標題
2. YT 影片說明文字（含歌詞）
3. YT 標記清單（Tags）
4. YT 封面提示詞（多版本，含鏡00快速方案）
5. IG 貼文文案（長版 + 短版）
6. IG 限動文案（3 版）
7. **Line / 通訊軟體 分享文字**（新）

---

## YT 影片說明結構

```
[一句點題的情境描述]

[空行]

──────────────────
🎵 歌詞
──────────────────

[完整歌詞]

──────────────────
🏷️ Tags
──────────────────

[標記清單]
```

---

## YT 標記策略（三層）

| 層次 | 類型 | 範例 |
|------|------|------|
| **精準層** | 歌名、核心主題 | 倒數的加班、辦公室暗戀 |
| **情境層** | 使用場景、族群 | 深夜歌單、上班族必聽 |
| **擴散層** | 風格類型、英文 | taiwan indie, sad song |

### 標記格式
- 中文標記：直接寫
- 英文標記：全小寫
- 每個標記後加英文逗號
- 總長度控制在 400/500 字以內（留緩衝）

### 通用標記庫
```
華語indie, 台灣原創音樂, 台灣indie, MV, 原創MV, AI音樂, AI生成音樂,
情歌, 失戀歌曲, 療癒音樂, 深夜歌單, 心情歌單, 獨立音樂, 華語流行,
mandopop, taiwan music, chinese indie, lofi, chill music, sad song
```

## YT 影片標題格式

```
[歌名] | [副標題，一句點題] 【Official AI MV】
```

範例：`不演了 | 太陽照樣升起，我照樣呼吸【Official AI MV】`

---

## YT 封面策略

### ⚡ 快速方案（推薦首選）
直接使用 **鏡00（前奏建立鏡）** 的圖片 → Canva 加上歌名白字 = 封面完成

**優點：**
- 零額外成本，不需重新生成圖片
- 背影 + 城市全景構圖天然百搭
- 在 Canva 加字時可同時匯出有字版（封面）與無字版（MV 用）

### 其他版本（需重新生成時使用）

**A 版 — 雙人情緒版**
- 兩位主角同框，情感距離感
- 適合：強調故事性

**B 版 — 主角獨照版**
- 主角臉部特寫 + 歌名文字
- 適合：強調角色記憶點

**C 版 — 物件象徵版**
- 道具俯拍靜物（手機/道具/場景物件）
- 適合：文青質感、歌詞系

**D 版 — 背影城市版**
- 主角背影長街/城市 + 歌名
- 適合：強調孤獨感、電影感

## IG 貼文撰寫原則

### 長版（首頁貼文）
- 開頭：2-3 句情境共鳴句（引起情緒連結）
- 中間：引導至 YT 連結
- 結尾：Hashtag（15-20 個）

### 短版（搭配 Reels）
- 一句話點題
- 直接放連結
- Hashtag 精簡（8-10 個）

### IG Hashtag 分類
| 類型 | 標籤 |
|------|------|
| 歌曲 | #歌名 |
| 情感 | #暗戀 #單戀 #失戀歌曲 #告白 |
| 場景 | #辦公室日常 #深夜IG #上班族 |
| 風格 | #華語indie #台灣原創 #情歌 #療癒系 |
| 格式 | #MV #AIMV #音樂分享 |

```
請幫我產出《[歌曲名稱]》的完整發布素材：

歌詞：[貼上 YT.txt 內容]
YT連結：[連結，若未上線可先留空]
主角設定：[簡述]
歌曲情境：[簡述]

請輸出：
1. YT 影片說明（含歌詞）
2. YT 標記（中英混合，400字以內）
3. YT 封面提示詞（A/B/C/D 四版）
4. IG 貼文長版
5. IG 貼文短版（Reels 用）
```

## 📱 Line / 通訊軟體 分享文字

上線後發給朋友的分享文，需要 YT 連結後才能生成。

### 格式（長版）
```
嘿！我出新歌了 🎵

《[歌名]》— [一句情境描述]

有做 MV 歡迎去看看，順手幫我按個讚跟訂閱🙏
[YT 連結]
```

### 格式（短版）
```
我出新歌了！有 MV 🎬
《[歌名]》歡迎收聽，幫我點個讚謝謝❤️
[YT 連結]
```

> **使用時機**：YT 影片上線後，把連結補進去就能直接傳。

3. YT 標記（中英混合，400字以內）

---

## 注意事項
- YT 說明的「點題句」要能在 2 秒內讓人有共鳴
- IG 貼文連結在貼文內無法點擊，要提醒放限動
- **封面首選：直接用鏡00 + Canva加字**，不需重新生成
- 標記總長度控制在 400 字以內
- Line 分享文字等 YT 上線後才能生成（需要連結）
