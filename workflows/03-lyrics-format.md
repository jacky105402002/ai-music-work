# Skill 1 — 歌詞整理（lyrics-format）

## 目標
將原始歌詞轉換為適合發布到 YouTube 的標準格式。

## 輸入
- `歌詞.txt`：原始歌詞（可能含英文段落標籤如 VERSE / CHORUS）
- 參考格式範本（如有前一首歌的 YT.txt 可作為參考）

## 輸出
- `YT.txt`：格式化完成的 YT 發布歌詞

---

## 格式規則

### 段落標籤（中文化）

| 原始標籤 | 轉換標籤 |
|---------|---------|
| VERSE / Verse | [主歌] |
| PRE-CHORUS | [橋段] |
| CHORUS | [副歌] |
| BREAK | [間奏] |
| BRIDGE | [橋接] |
| OUTRO | [尾聲] |
| INTRO | [前奏] |

### 排版規則
1. 段落標籤單獨一行，用 `[ ]` 包住
2. 標籤後不空行，直接接歌詞
3. 歌詞段落結束後加 `⸻` 分隔線
4. 分隔線後空一行再接下一段落標籤
5. 同一段落內的邏輯分組之間可空一行

### 範例格式
```
[主歌]
第一句歌詞
第二句歌詞
第三句歌詞
⸻

[副歌]
副歌第一句
副歌第二句
⸻
```

---

## Claude 操作提示

```
請幫我整理這首歌的歌詞，格式參考 [參考檔案路徑]
規則：
- 段落標籤改為中文（VERSE→主歌、CHORUS→副歌、BREAK→間奏）
- 每段結尾加 ⸻ 分隔線
- 段落間空一行
- 輸出為 YT.txt 儲存到 [路徑]
```

---

## 注意事項
- 若原始歌詞沒有明確標籤，請根據歌詞重複性與情緒判斷段落
- 橋段（Pre-Chorus）如果存在，獨立標出，不要併入主歌
- 尾聲的哼唱（如「嗯 嗯 嗯」）保留，單獨一行
