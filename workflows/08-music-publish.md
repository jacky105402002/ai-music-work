# Skill 6 — 發布內容生成（music-publish）

## 目標
根據歌曲資訊，一次產出所有社群發布所需的文案素材。

## 輸入
- 歌曲名稱
- `YT.txt`：格式化歌詞
- YT 影片連結（上線後補入）
- 封面風格選擇

## 輸出
1. YT 影片說明文字
2. YT 標記清單（Tags）
3. YT 封面圖片提示詞（多版本）
4. IG 貼文文案（長版 + 短版）
5. IG 限動文案

---

## YT 影片說明結構

```
[一句點題的情境描述]

[空行]

──────────────────
🎵 歌詞
──────────────────

[完整歌詞]

──────────────────
🏷️ Tags
──────────────────

[標記清單]
```

---

## YT 標記策略（三層）

| 層次 | 類型 | 範例 |
|------|------|------|
| **精準層** | 歌名、核心主題 | 倒數的加班、辦公室暗戀 |
| **情境層** | 使用場景、族群 | 深夜歌單、上班族必聽 |
| **擴散層** | 風格類型、英文 | taiwan indie, sad song |

### 標記格式
- 中文標記：直接寫
- 英文標記：全小寫
- 每個標記後加英文逗號
- 總長度控制在 400/500 字以內（留緩衝）

### 通用標記庫
```
華語indie, 台灣原創音樂, 台灣indie, MV, 原創MV, AI音樂, AI生成音樂,
情歌, 失戀歌曲, 療癒音樂, 深夜歌單, 心情歌單, 獨立音樂, 華語流行,
mandopop, taiwan music, chinese indie, lofi, chill music, sad song
```

## YT 封面提示詞版本框架

### A 版 — 雙人情緒版
- 兩位主角同框，情感距離感
- 適合：強調故事性

### B 版 — 主角獨照版
- 主角臉部特寫 + 歌名文字
- 適合：強調角色記憶點

### C 版 — 物件象徵版
- 道具俯拍靜物（咖啡、便條紙、鍵盤）
- 適合：文青質感、歌詞系

### D 版 — 背影走廊版
- 主角背影長廊 + 歌名
- 適合：強調孤獨感、電影感

## IG 貼文撰寫原則

### 長版（首頁貼文）
- 開頭：2-3 句情境共鳴句（引起情緒連結）
- 中間：引導至 YT 連結
- 結尾：Hashtag（15-20 個）

### 短版（搭配 Reels）
- 一句話點題
- 直接放連結
- Hashtag 精簡（8-10 個）

### IG Hashtag 分類
| 類型 | 標籤 |
|------|------|
| 歌曲 | #歌名 |
| 情感 | #暗戀 #單戀 #失戀歌曲 #告白 |
| 場景 | #辦公室日常 #深夜IG #上班族 |
| 風格 | #華語indie #台灣原創 #情歌 #療癒系 |
| 格式 | #MV #AIMV #音樂分享 |

## Claude 操作提示

```
請幫我產出《[歌曲名稱]》的完整發布素材：

歌詞：[貼上 YT.txt 內容]
YT連結：[連結，若未上線可先留空]
主角設定：[簡述]
歌曲情境：[簡述]

請輸出：
1. YT 影片說明（含歌詞）
2. YT 標記（中英混合，400字以內）
3. YT 封面提示詞（A/B/C/D 四版）
4. IG 貼文長版
5. IG 貼文短版（Reels 用）
```

---

## 注意事項
- YT 說明的「點題句」要能在 2 秒內讓人有共鳴
- IG 貼文連結在貼文內無法點擊，要提醒放限動
- 封面建議生成 3-4 張後 A/B 測試點擊率
- 標記定期更新，可根據演算法趨勢調整
