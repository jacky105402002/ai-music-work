# Skill 2 — MV 分鏡規劃（mv-storyboard）

## 目標
根據歌詞內容與歌曲主題，生成完整的 MV 分鏡腳本 Markdown 檔案。

## 輸入
- `YT.txt`：格式化歌詞
- 歌曲主題描述（情境、情緒、風格）
- 角色基本設定（性別、職業、關係）

## 輸出
- `MV分鏡.md`：完整分鏡腳本

---

## MV分鏡.md 結構

```markdown
# 🎬 [歌曲名稱] — MV 分鏡規劃

> 主題：...
> 色調基調：...

## 🎭 角色設定
## 📍 場景設定
## 🎞️ 分鏡腳本（按段落）
## 🎨 視覺風格備註
## 📋 拍攝 Checklist
```

---

## 分鏡腳本規則

### 每個鏡號包含
| 欄位 | 說明 |
|------|------|
| 鏡號 | 兩位數編號（01, 02...） |
| 畫面描述 | 具體說明畫面內容 |
| 鏡頭 | 特寫 / 中景 / 廣角 / 俯拍 / 跟拍 等 |
| 時長 | 建議秒數（2s ~ 5s） |

### 時長分配原則
| 段落 | 每鏡時長 | 節奏 |
|------|---------|------|
| 前奏 | 3-4s | 慢，建立氛圍 |
| 主歌 | 3-4s | 穩定敘事 |
| 橋段 | 2-3s | 漸漸加速 |
| 副歌 | 2-3s | 快切情緒爆發 |
| 間奏 | 3-4s | 留白 |
| 尾聲 | 4-5s | 慢，收斂情緒 |

### 鏡頭類型參考
- **固定**：靜止畫面，強調靜謐
- **慢推**：緩慢推進，增加張力
- **特寫**：臉部/手部/道具，情緒細節
- **中景**：半身，人物動作
- **廣角**：環境，空間感
- **俯拍**：上帝視角，孤獨感
- **跟拍**：跟隨角色移動
- **逆光**：門口/窗邊，剪影感

## Claude 操作提示

```
根據以下歌詞幫我規劃 MV 分鏡：

歌詞：[貼上 YT.txt 內容]

設定：
- 主題：[描述故事主軸]
- 主角：[性別、職業、個性]
- 對象：[性別、職業、個性]
- 色調：[暖色/冷色/混合]

請輸出完整 MV分鏡.md，包含角色設定、場景設定、
逐句分鏡、視覺風格備註、拍攝 Checklist。
儲存到 [路徑]
```

---

## 注意事項
- 每句或每兩句歌詞對應一個分鏡
- 副歌第一次與第二次分鏡可不同（第二次情緒更強）
- 間奏/尾聲善用靜物空鏡（道具、窗景）增加留白
- 記憶閃回片段建議用暖色過曝的拼貼格局處理
