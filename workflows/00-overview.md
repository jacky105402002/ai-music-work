# 00 — 完整工作流程總覽

## 流程圖

```
┌─────────────────────────────────────────────────────┐
│                    INPUT                            │
│         原始歌詞.txt  +  歌曲.mp3                     │
└──────────────────────┬──────────────────────────────┘
                       │
              ┌────────▼────────┐
              │   Skill 1       │  工具：Claude

              │ lyrics-format   │
              └────────┬────────┘
                       │ YT.txt
              ┌────────▼────────┐
              │   Skill 2       │  工具：Claude
              │  MV 分鏡規劃    │  時間：20 分鐘
              │ mv-storyboard   │
              └────────┬────────┘
                       │ MV分鏡.md
              ┌────────▼────────┐
              │   Skill 3       │  工具：Claude + 參考圖
              │   角色設定      │  時間：15 分鐘
              │ character-setup │
              └────────┬────────┘
                       │ 角色描述字串
              ┌────────▼────────┐

              └────────┬────────┘
                       │ MV分鏡_提示詞.md
                       │
         ┌─────────────▼─────────────┐
         │      手動步驟：圖片生成     │  工具：Gemini
         │  - 先生成角色參考圖         │  時間：60-120 分鐘

         │  - 整理命名 01.png ~ N.png │
         └─────────────┬─────────────┘

              │   Skill 5       │  工具：Claude（讀圖）

              │ music-publish   │
              └────────┬────────┘
                       │
┌──────────────────────▼──────────────────────────────┐
│                    OUTPUT                           │
│  YT 影片說明 / 標記 / 封面 / IG 貼文 / 限動文案       │
└─────────────────────────────────────────────────────┘
```

## 檔案命名規範

### 歌曲資料夾結構
```
music/
└── [歌曲名稱]/
    ├── 歌詞.txt              # 原始歌詞
    ├── YT.txt                # Skill 1 輸出
    ├── MV分鏡.md             # Skill 2 輸出
    ├── MV分鏡_提示詞.md      # Skill 4 輸出
    ├── 分鏡圖片/             # Gemini 生成圖片
    │   ├── 01.png
    │   ├── 02.png
    │   └── ...
    ├── [歌曲名稱].mp3        # 原始音樂
    ├── [歌曲名稱].mp4        # 完整 MV
    ├── [歌曲名稱]-短版.mp4   # IG Reels 版
    └── 封面-[尺寸].png       # YT 封面
```

### 分鏡圖片命名
- 格式：`[鏡號].png`（兩位數，補零）
- 範例：`01.png`, `12.png`, `35.png`
- 修正版：`17-v2.png`（加版本號）
