# Skill 2 — Mureka 製作循環（mureka-cycle）

## 目標
以 Mureka.ai 為核心工具，透過「生成 → 試聽 → 分析 → 調整」的反覆循環，
同步完成**歌詞修正、情感核心確認、音樂質感定型**，最終選出正式歌曲版本。

## 輸入
- `歌詞草稿.txt`（Skill 1 輸出）
- Intake 表單（風格欄位）

## 輸出
- 選定歌曲 MP3
- 最終確認歌詞（可能與草稿有差異）
- 選定的風格標籤字串（供後續參考）

---

## 核心概念：音樂是最好的歌詞顧問

> 「歌詞看起來沒問題，但聽起來哪裡怪」
> 這種感覺只有生成音樂後才會浮現。
> **Mureka 循環的本質，是用音樂來校正歌詞與情感。**

---

## 完整循環流程

```
┌─────────────────────────────────────────────────┐
│              Mureka 製作循環                     │
│                                                 │
│  Step 1  Claude 生成初始風格標籤               │
│          └→ 根據 Intake 表單輸出 2-3 組標籤    │
│                                                 │
│  Step 2  格式化歌詞（英文段落標籤）             │
│          └→ [verse][chorus][bridge] 等          │
│                                                 │
│  Step 3  丟入 Mureka 生成                       │
│          └→ 每組標籤生成 2-3 首                 │
│                                                 │
│  Step 4  人工試聽                               │
│          └→ 用「試聽反饋表」記錄感受            │
│                                                 │
│  Step 5  Claude 分析反饋                        │
│          └→ 診斷問題出在風格 or 歌詞            │
│          └→ 給出具體調整建議                    │
│                                                 │
│  Step 6  執行調整                               │
│   ├→ A. 調整風格標籤 → 回 Step 3              │
│   ├→ B. 修改歌詞段落 → 回 Step 2              │
│   └→ C. 同時調整    → 回 Step 2              │
│                                                 │
│  重複直到滿意 ✅                                │
└─────────────────────────────────────────────────┘
```

## Step 1：初始風格標籤生成

### Claude 操作提示
```
根據以下 Intake 表單的音樂風格欄位，
幫我生成 Mureka 初始風格標籤：

曲風：[填入]
節奏：[填入]
情緒：[填入]
樂器偏好：[填入]
演唱性別：[填入]

請輸出：
1. 主要風格標籤字串（英文，逗號分隔）
2. 兩個變體版本（調整一個維度，如節奏/樂器/人聲）
3. 說明每個版本預期的音樂質感差異
```

### 風格標籤結構
```
[流派], [子流派], [情緒1], [情緒2], [人聲], [樂器1], [樂器2],
[速度], [特殊描述], chinese lyrics
```

## Step 2：歌詞格式化規則

Mureka 使用英文小寫段落標籤：

| 中文標籤 | Mureka 標籤 |
|---------|-----------|
| 前奏 | `[intro]` |
| 主歌 | `[verse]` |
| 橋段 | `[pre-chorus]` |
| 副歌 | `[chorus]` |
| 橋接 | `[bridge]` |
| 間奏 | `[break]` |
| 尾聲 | `[outro]` |
| 最終副歌 | `[chorus]`（重複即可）|

> `[intro]` 和 `[outro]` 和 `[break]` 可以空白，讓 Mureka 自由發揮

| 副歌 | ✅好 / ⚠️普通 / ❌不對 | |

### 整體感受
- 情緒方向對嗎？□ 對 □ 不對，感覺比較像：
- 最喜歡哪段：

## Step 5：Claude 分析反饋

### Claude 操作提示
```
我用以下風格標籤生成了一首歌，試聽後的反饋如下：

風格標籤：[貼上]
歌詞：[貼上]
試聽反饋：[貼上填好的反饋表]

請分析：
1. 問題出在「風格標籤」還是「歌詞本身」？
2. 如果是風格標籤問題 → 給我調整後的新標籤
3. 如果是歌詞問題 → 具體指出哪幾句，給 2-3 個修改版本
4. 如果兩者都要改 → 分開給建議
```

## Step 6：常見問題與調整方向

### 問題診斷表

| 聽起來的問題 | 可能原因 | 調整方向 |
|------------|---------|---------|
| 整體太平，沒有起伏 | 標籤缺少 `slow build` / `emotional climax` | 加入動態描述標籤 |
| 副歌沒有爆發 | 標籤沒有 `emotional peak` 或樂器不夠 | 加 `strings` / `full arrangement` |
| 主歌太吵，沒有鋪陳感 | 標籤缺少 `minimal verse` | 加 `sparse arrangement in verse` |
| 人聲太重/太輕 | `soft` 或 `powerful` 用錯 | 調整人聲描述字 |
| 情緒方向跑偏 | 情緒標籤不準 | 換更精確的情緒詞 |
| 歌詞某段唱起來卡 | 字數過多或聲調問題 | 精簡該段歌詞，減少每行字數 |
| 某段歌詞意思對但聽起來沒感覺 | 太抽象，缺乏畫面 | 換成具體意象（地點、動作、物件）|

### 歌詞修改原則
- **主歌太滿** → 每行減少 1-2 個字，留呼吸空間
- **副歌記憶點不夠** → 核心句要更短、更直接、更重複
- **Bridge 沒有轉折感** → 加一句與前面情緒「反差」的句子
- **尾聲太普通** → 換成意象結尾，不要解釋，讓聽眾自己感受

yearning（渴求）       wistful（感傷）         vulnerable（脆弱）

```

```

## 選歌評估標準

| 維度 | 評估問題 |
|------|---------|
| **情緒匹配** | 聽完有沒有你想要的「那種感覺」？ |
| **旋律記憶點** | 副歌能不能讓你哼出來？ |
| **編曲層次** | 主歌鋪陳、副歌爆發的層次感有沒有？ |
| **人聲質感** | 聲線符合主角的感覺嗎？ |
| **整體時長** | 是否符合預期的 MV 長度需求？ |
