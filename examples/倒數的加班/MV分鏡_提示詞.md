## 🎭 角色基準描述（Character Reference Prompts）

> ⚠️ **使用方式**：每次開新 session 生成角色圖時，先單獨生成一張「角色參考圖」，之後同 session 內的分鏡圖都能維持一致性。
> **男主角是暗戀方（敘述視角的「我」）**，女主角是被暗戀的同事。

## 💡 使用建議

| 項目 | 建議 |
|------|------|
| **生成尺寸** | 1920×1080（16:9）或 1280×720 |
| **每張圖建議生成數量** | 3～4 張，挑選最佳的 |
| **人物一致性** | Gemini 同一 session 內連續生成可維持角色一致性，建議主角、對象各用獨立 session |
| **Canva 剪輯建議** | 靜態圖片建議搭配 Ken Burns 效果（緩慢推近/拉遠）增加動感 |
| **情緒段落色調** | 主歌偏暖黃、橋段轉中性、副歌偏冷藍、尾聲暖冷混合 |
