# 00 — 完整工作流程總覽

## 流程圖

```
┌─────────────────────────────────────────────────────┐
│                    INPUT                            │
│              一個歌曲概念 / 主題 / 情境               │
└──────────────────────┬──────────────────────────────┘
                       │
              ┌────────▼────────┐
              │   Skill 0       │  工具：Claude
              │   歌曲企劃      │  時間：10 分鐘
              │  song-brief     │  → Intake 表單
              └────────┬────────┘
                       │
              ┌────────▼────────┐
              │   Skill 1       │  工具：Claude
              │   歌詞創作      │  時間：15 分鐘
              │ lyrics-writing  │  → 歌詞草稿.txt
              └────────┬────────┘
                       │
         ┌─────────────▼─────────────┐
         │    ✏️ 人工：修改歌詞        │  時間：不限
         │  - 調整用字、押韻、情感    │  可來回多次
         │  - Claude 輔助修改潤色    │
         └─────────────┬─────────────┘
                       │ 確認版歌詞
              ┌────────▼────────┐
              │   Skill 2       │  工具：Claude
              │  Mureka 提示詞  │  時間：10 分鐘
              │ mureka-prompt   │  → 風格標籤 + 格式化歌詞
              └────────┬────────┘
                       │
         ┌─────────────▼─────────────┐
         │   🎵 人工：Mureka 生成     │  工具：mureka.ai
         │  - 貼入風格標籤 + 歌詞    │  時間：30-60 分鐘
         │  - 生成多個版本           │
         │  - 人工挑選最佳版本       │
         └─────────────┬─────────────┘
                       │ 選定歌曲 MP3
              ┌────────▼────────┐
              │   Skill 3       │  工具：Claude
              │   歌詞整理      │  時間：10 分鐘
              │ lyrics-format   │  → YT.txt
              └────────┬────────┘
                       │
              ┌────────▼────────┐
              │   Skill 4       │  工具：Claude
              │  MV 分鏡規劃    │  時間：20 分鐘
              │ mv-storyboard   │  → MV分鏡.md
              └────────┬────────┘
                       │
              ┌────────▼────────┐
              │   Skill 5       │  工具：Claude + 參考圖
              │   角色設定      │  時間：15 分鐘
              │ character-setup │  → 角色描述字串
              └────────┬────────┘
                       │
              ┌────────▼────────┐
              │   Skill 6       │  工具：Claude
              │  分鏡提示詞     │  時間：20 分鐘
              │  shot-prompts   │  → MV分鏡_提示詞.md
              └────────┬────────┘
                       │
         ┌─────────────▼─────────────┐
         │   🖼️ 人工：Gemini 圖片生成  │  工具：Gemini
         │  - 先生成角色參考圖        │  時間：60-120 分鐘
         │  - 逐鏡生成（同Session）  │
         │  - 整理命名 01.png...     │
         └─────────────┬─────────────┘
                       │
              ┌────────▼────────┐
              │   Skill 7       │  工具：Claude（讀圖）
              │  分鏡圖片審核   │  時間：20 分鐘
              │  shot-review    │  → 審核報告 + 修正提示詞
              └────────┬────────┘
                       │
         ┌─────────────▼─────────────┐
         │   🎬 人工：Canva 剪輯      │  工具：Canva
         │  - 匯入分鏡圖片           │  時間：60-120 分鐘
         │  - Ken Burns 動態效果     │
         │  - 加入歌詞字幕           │
         │  - 加入音樂               │
         │  - 製作片尾字卡           │
         └─────────────┬─────────────┘
                       │
              ┌────────▼────────┐
              │   Skill 8       │  工具：Claude
              │  發布內容生成   │  時間：15 分鐘
              │ music-publish   │  → YT說明/標記/封面/IG文案
              └────────┬────────┘
                       │
┌──────────────────────▼──────────────────────────────┐
│                    OUTPUT                           │
│       完整 MV + 社群發布素材 + 歌曲上架              │
└─────────────────────────────────────────────────────┘
```

## 時間估算

| 步驟 | 類型 | 預估時間 |
|------|------|---------|
| Skill 0 歌曲企劃 | Claude 自動 | 10 分鐘 |
| Skill 1 歌詞創作 | Claude 自動 | 15 分鐘 |
| ✏️ 人工修改歌詞 | **手動** | 不定（30分-數小時）|
| Skill 2 Mureka 提示詞 | Claude 自動 | 10 分鐘 |
| 🎵 Mureka 生成選歌 | **手動** | 30-60 分鐘 |
| Skill 3 歌詞整理 | Claude 自動 | 10 分鐘 |
| Skill 4 MV 分鏡規劃 | Claude 自動 | 20 分鐘 |
| Skill 5 角色設定 | Claude 自動 | 15 分鐘 |
| Skill 6 分鏡提示詞 | Claude 自動 | 20 分鐘 |
| 🖼️ Gemini 圖片生成 | **手動** | 60-120 分鐘 |
| Skill 7 圖片審核 | Claude 自動 | 20 分鐘 |
| 🎬 Canva 剪輯 | **手動** | 60-120 分鐘 |
| Skill 8 發布內容 | Claude 自動 | 15 分鐘 |
| **總計** | | **約 6-10 小時** |

---

## 人工決策點（不可自動化）

| 決策點 | 說明 |
|--------|------|
| ✏️ 歌詞修改 | 情感、用字、押韻是創作核心，保留人工掌控 |
| 🎵 選歌 | Mureka 會生成多個版本，風格喜好只有人能判斷 |
| 🖼️ 選圖 | 每鏡建議生成 3-4 張，挑最符合情緒的 |
| 🎬 剪輯節奏 | 音樂與畫面的搭配感，由人決定 |
