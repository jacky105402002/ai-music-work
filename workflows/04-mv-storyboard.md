# Skill 2 — MV 分鏡規劃（mv-storyboard）

## 目標
根據歌詞內容與歌曲主題，生成完整的 MV 分鏡腳本 Markdown 檔案。

## 輸入
- `YT.txt`：格式化歌詞
- 歌曲主題描述（情境、情緒、風格）
- 角色基本設定（性別、職業、關係）

## 輸出
- `MV分鏡.md`：完整分鏡腳本

---

## MV分鏡.md 結構

```markdown
# 🎬 [歌曲名稱] — MV 分鏡規劃

> 主題：...
> 色調基調：...

## 🎭 角色設定
## 📍 場景設定
## 🎞️ 分鏡腳本（按段落，含鏡00）
## 🎨 視覺風格備註
## 📋 Session 分組（A/B）
```

---

## 分鏡腳本規則

### ⚠️ 分鏡總數建議

| 歌曲長度 | 建議總鏡數 | 說明 |
|---------|-----------|------|
| 2.5~3 分鐘 | 18~22 鏡 | 精簡版 |
| 3~4 分鐘 | 22~26 鏡 | 標準版（不演了為 25 鏡） |
| 4 分鐘以上 | 26~32 鏡 | 豐富版 |

> **不要每句歌詞都分一鏡**，副歌同一段情緒可合併；閃回片段建議 2-3 鏡而非拆散。

---

### 🎬 鏡00：前奏建立鏡（必備）

**每首歌的前奏都必須規劃 鏡00**，原因：
1. 建立整體世界觀與視覺基調
2. 可直接兼作 **YouTube 封面**（Canva 加字即可，不需重新生成）
3. 前奏通常無人聲，適合靜態廣角構圖

**鏡00 構圖建議：**
- 廣角，主角或場景的建立鏡
- 主角背影 + 城市/環境全景（最百搭）
- 色調代表整首歌的基調

---

### 每個鏡號包含
| 欄位 | 說明 |
|------|------|
| 鏡號 | 00 為前奏，01 起為正片 |
| **入點** | 該鏡開始的時間（如 0:18） |
| **出點** | 該鏡結束的時間（如 0:26） |
| 時長 | 出點 - 入點（秒） |
| 畫面描述 | 具體說明畫面內容 |
| 鏡頭 | 特寫 / 中景 / 廣角 / 俯拍 / 跟拍 等 |

> 入點/出點從 `歌詞.txt` 的時間戳推導，供 Canva 剪輯對齊使用。

### 時長分配原則
| 段落 | 每鏡時長 | 節奏 |
|------|---------|------|
| 前奏（鏡00） | 10-17s | 慢推入，建立氛圍 |
| 主歌 | 6-9s | 穩定敘事 |
| 橋段 | 4-6s | 漸漸加速 |
| 副歌 | 5-10s | 情緒爆發，鏡數多 |
| 橋接 | 4-6s | 沉靜，告別 |
| 最終副歌 | 8-12s | 最高潮，慢推近 |
| 片尾字卡 | 5-8s | 直接 Canva 製作，不需 Gemini |

### 鏡頭類型參考
- **固定**：靜止畫面，強調靜謐
- **慢推**：緩慢推進，增加張力
- **特寫**：臉部/手部/道具，情緒細節
- **中景**：半身，人物動作
- **廣角**：環境，空間感
- **俯拍**：上帝視角，孤獨感
- **跟拍**：跟隨角色移動
- **逆光**：門口/窗邊，剪影感

## Claude 操作提示

```
根據以下歌詞幫我規劃 MV 分鏡：

歌詞：[貼上 YT.txt 內容]

設定：
- 主題：[描述故事主軸]
- 主角：[性別、職業、個性]
- 對象：[性別、職業、個性]
- 色調：[暖色/冷色/混合]

請輸出完整 MV分鏡.md，包含角色設定、場景設定、
逐句分鏡、視覺風格備註、拍攝 Checklist。
儲存到 [路徑]
```

---

## 注意事項
- 前奏**必須規劃鏡00**，可兼作 YT 封面
- 分鏡包含**入點/出點**，對應歌詞時間戳，Canva 剪輯才能精準對齊
- 副歌第一次與第二次分鏡可不同（第二次情緒更強）
- 橋接/尾聲善用靜物空鏡（道具、窗景）增加留白
- 閃回片段建議暖色過曝處理，與現在時態做色調區分
- 片尾字卡（歌名字卡）直接在 **Canva** 製作，不需 Gemini 生成
- 最後加上 **Session 分組表**（哪些鏡用 Session A，哪些用 Session B）

## 📋 Session 分組建議

多角色的 MV 建議分兩個 Gemini Session，維持角色一致性：

| Session | 包含鏡號 | 說明 |
|---------|---------|------|
| **Session A** | 現在場景、單一主角 | 先生成角色參考圖再批次生成 |
| **Session B** | 閃回場景、雙角色 | 同上，以閃回色調為基礎 |
